# Webtech-Exp5
To create web pages which demonstrate the applications of document object model and events in JavaScript.

Description:
In this experiment, different JavaScript programs are implemented to demonstrate DOM manipulation and event handling. The programs include finding the shortest and longest words, calculating BMI, generating a fruit garden, converting currencies, flipping a coin and calculating the cost of a birthday cake order.


Procedure:

1.	Open Visual Studio Code and create an HTML file named index.html.
2.	Create the basic HTML5 structure using the required tags.
3.	Add headings, paragraphs, images, and other webpage elements.
4.	Create a CSS file named style.css and link it to the HTML file.
5.	Apply border-radius to create rounded corners.
6.	Use border images and multiple backgrounds to style the elements.
7.	Apply linear and radial gradients for attractive backgrounds.
8.	Use text-shadow and box-shadow to add shadow effects.
9.	Use media queries to make the webpage responsive.
10.	Save the files and open the webpage in a browser to check the output.
